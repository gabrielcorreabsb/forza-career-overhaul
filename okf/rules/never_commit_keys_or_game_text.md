# Never commit the CMS key, the Mod Tool or plain game files

No AES key, no Forza Mod Tool or anything extracted from it, and no plain-text copies of game files in any contribution. Cite names, paths, counts and conclusions instead.

Full text and rationale: `docs/project/THIRD_PARTY.md`.
