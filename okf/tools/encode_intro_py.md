# `encode_intro.py`

Section: 2. Kit generation

from one 16:9 MP4 to an own intro video: encodes Bink 2 KB2j (1920×1080 and 3840×2160, preset quantiser 8, audio quality 10) with an ffmpeg that has bink2video, installs both files (bk2_install.py) and adds their index records (hash_manifest_edit.py); only creates new files (an existing name is refused); dry-run by default
